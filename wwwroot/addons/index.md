# Addons

Here you can find a list of all the official/partnered addons for TKVSC!

You can find the full official plugin repo [here](https://github.com/TKVSC-Team/tkvsc-addons).
<br>

## TKMM-CLI
Integrates the TKMM CLI into TKVSC. This acts as a library for other plugins, and allows .tkcl packaging within VSCode.

    <a class="download-btn" id="download-addon" href="https://downloads.tkvsc.dev/addons/tkmm-cli/latest">Download</a>
</div>
